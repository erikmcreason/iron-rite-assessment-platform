# Iron Rite Assessment Platform

## Purpose

This repository contains the early development work for the Iron Rite Assessment Platform, a human assessment system designed to evaluate archetype development, shadow patterns, behavioral tendencies, and personal growth opportunities.

The project is being built as both a learning vehicle and a portfolio artifact.

## Current Focus

The current version is a command-line Python application that is evolving from a simple archetype tracker into a structured assessment platform.

## Current Capabilities

- Add assessment records
- View stored records
- Update records
- Delete records
- Save data with JSON
- Load data with JSON
- Generate basic reports
- Identify dominant archetype
- Identify growth area
- Generate recommendations

## Planned Capabilities

- Question engine
- Scoring engine
- Archetype subtype scoring
- Shadow archetype analysis
- Report generation
- Visual dashboards
- Portfolio-quality documentation

## Archetype Model

The system is based on four primary archetypes:

- King
- Warrior
- Magician
- Lover

Each archetype will eventually include healthy and shadow expressions.

## Development Philosophy

This project is being built through practical software engineering repetition:

- Build small
- Understand the concept
- Improve the system
- Document progress
- Publish evidence

## Current Status

Early prototype.

The next major milestone is the Assessment Question Engine.
